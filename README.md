# 3Dyaozao · 手势陶艺手作

一个**单文件**的 3D 柴烧陶艺交互作品：用摄像头识别手势，在浏览器里从「立意」一路做到「成器」——备泥、拉坯、修坯、装饰、施釉、烧成，全程可在转盘、釉缸、窑炉三种环境间切换，最后按鉴赏维度生成结构化的成器说明。

打开 `index.html` 即可运行，无需构建、无需后端。

## 在线体验

- 演示地址：`https://yeeie555.github.io/3Dyaozao/`
- 仓库地址：`https://github.com/Yeeie555/3Dyaozao`

## 核心特性

**手作八步流程**
立意 → 备泥 → 拉坯 → 修坯 → 装饰 → 施釉 → 烧成 → 成器。左侧「工艺工坊」面板会随步骤切换参数项，并始终提示当前处在第几步。

**手势驱动**
基于 MediaPipe Hands 做手部追踪，识别开窝、提拉、收束、修坯横刮、拍打定型等动作；手数（单手／双手）与当前动作及作用实时显示。没有摄像头时可用鼠标替代：`Shift+拖动` 竖直＝提拉/下压、横向＝修坯，`Shift+滚轮`＝捏合/外扩。

**自研软光栅 3D 渲染**
无第三方 3D 库，回转体网格 + 透视投影 + 背面剔除 + 画家算法 + 朗伯/环境光/高光，纯 Canvas 2D 绘制。

**参数会真的影响画面**
- **泥料**：五种泥各有专属胎色与颗粒质地（粗陶大砂粒、红泥铁质密点、紫砂砂点伴云母亮闪、细白近无颗粒、混合练泥双色混杂）
- **成型手法与肌理**：轮制螺旋纹、手捏指压痕、盘筑层棱、泥板拼缝、模具极平；肌理则有拍打凹痕、刮削纵纹、刻线暗沟、磨光晶亮、化装土提亮
- **施釉方式**：浸釉匀亮、刷釉竖痕、喷釉雾面哑光、荡釉下段积釉垂流，各有独立动画
- **窑位与薪柴**：窑腔余烬辉光与火苗高度随受火强度变化，火色随薪柴碱性变化
- **开窑动画**：点击烧制后关窑 → 烧制 → 开窑，出窑后才由生坯转为成瓷

## 目录结构

```
index.html              # 构建产物（单文件应用，也是 GitHub Pages 入口）
src/
  index.html            # 页面结构与样式（源）
  app.js                # 全部逻辑：渲染、状态机、手势、面板（源）
  build.py              # 把 app.js 内联进 index.html，产出根目录 index.html
  e2e-test.js           # 端到端测试（Node 桩驱动，51 项断言）
  diff-test.js          # 渲染指纹比对（手法/肌理/生坯↔成瓷可辨性）
  clay-kiln-test.js     # 泥料与窑炉渲染差异专项
kiln-kb/                # 柴烧鉴赏知识库（文本语料，供文案与鉴赏口径参考）
```

## 开发

修改 `src/index.html` 或 `src/app.js` 后重新构建：

```bash
cd src
python build.py          # -> ../index.html
```

## 测试

沙箱环境无法启动无头 Edge，因此用 Node + `vm` 构造 fake DOM/Canvas 逐帧驱动渲染，再从绘制调用的颜色与几何反推视觉差异。

```bash
cd src
node e2e-test.js         # 端到端：流程、面板文案、导航、施釉/烧成动画
node diff-test.js        # 五种手法、六种肌理、生坯↔成瓷的指纹互异
node clay-kiln-test.js   # 五种泥料指纹互异；窑位/薪柴切换画面有差异
```
